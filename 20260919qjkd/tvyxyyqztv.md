# 孕妇孕晚期可以吃脆李吗

> 更新时间：2026-09-19 (UTC+8)

孕晚期时胎儿即将临盆，很多孕妇在此时容易出现焦虑、紧张的情绪，精神状态不佳，从而影响食欲。此时，孕妇可以吃一些具有开胃生津、促进消化的作用的食物。脆李吃起来清脆爽口、甜中带酸，可以促进食欲，那么，孕妇孕晚期可以吃脆李吗?
孕妇孕晚期可以吃脆李吗
　　孕妇孕晚期可以吃脆李。李子营养非常丰富，含有各种的维生素和微量元素，还有蛋白质，脂肪，里面含有微量元素钙、磷、铁，还有氨基酸。

　　孕妇在孕晚期吃李子的好处：

　　1、促进消化

　　对于孕妇来说，李子具有很好的促进消化的作用。李子能促进胃酸和胃消化酶的分泌，有增加肠胃蠕动的作用，因而食李能促进消化，增加食欲，为胃酸缺乏、食后饱胀、大便秘结者的食疗良品。

　　2、清肝利水

　　在传统中医里面，李子具有情感离水的作用。新鲜李肉中含有多种氨基酸，如谷酰胺、丝氨酸、甘氨酸、脯氨酸等，生食之对于治疗肝硬化腹水大有种益。

　　3、缓解便秘。还能促进肠道的蠕动过程，所以能预防便秘问题。我们知道，怀孕女性在孕晚期的时候，因为子宫不停扩大会压缩到肠道部位，所以便秘的情况比较常见，而吃点脆李这样的问题就会远离你。

　　4、生津止渴。多吃脆李的话还能达到生津止渴的效果，有一部分孕期女性她们是做老师、做客服的，所以经常会感到口渴，这时候也可以吃一点脆李来缓解。
李子的功效与作用
　　1. 健胃消食。李子是味酸的有促进胃酸和胃消化酶的分泌，并能促进胃肠蠕动，因而李子有改善食欲、促进消化的作用，尤其是对于那些胃酸比较缺乏，事后出现胀饱的患者有一定的效果。

　　2. 降压。李子核仁中含苦杏仁甙和大最的脂肪油，经药理证实，它有着重著的利水降压的作用，并可加快人体肠道蠕动，促进干燥的大便快速排出，减少肠道对大便中有毒物质的吸收，同时也具有止咳祛痰的作用。

　　3. 美容养颜。美容效果显著的就是李树上开出的花，俗称李花，李花颜色洁白，气味清新，味苦气香，外用可以除粉刺，使颜面有光泽。如果将李子汁酿成酒，饮后可以美容防衰老。将李子的果核研磨后，调上鸡蛋蛋液，洁面后涂在面部，还可以祛除脸上的黑点等杂质。

　　4. 利尿消肿。新鲜李肉中的丝氨酸、甘氨酸、脯氨酸、谷酰胺等氨基酸有利尿消肿的作用。
