# 【关注】如何管理癫痫患儿心理与安全 神经外科专家来支招

> 更新时间：2026-09-17 (UTC+8)

癫痫俗称“羊角风”，是小儿时期常见的一种病因复杂的、反复发作的神经系统综合征。是由阵发性、暂时性脑功能紊乱所致的惊厥发作。临床表现为反复发作的肌肉抽搐、意识、感觉及情感等方面短暂异常。

儿童时期的癫痫发作有潜在的和长远的注意力、思维能力、认知损害等风险，长期发作给患儿及家属带来沉重的心理负担。绝大部分患儿的家长开始会刻意对其隐瞒真实的病情。随着年龄的增长患儿对癫痫知识的渴望与日俱增。

那家长应该怎么做呢？

家长们应该在专业医生的协助下教会患儿如何在日常生活中应对癫痫发作，保护自己的生命安全，化解由癫痫发作带来的恐惧。着重训练患儿自我管理疾病的技能（比如记癫痫日志、按时服药、定期随访等）、基本的独立生活技能、健康的生活方式等。还应该重视患儿情绪和精神方面的问题，努力培养他们的社交能力。但家长的过度担心和保护会造成患儿过分依赖，以致成年后缺乏独立生活能力。

癫痫患儿会对娱乐和运动的需求很高，家长需要帮助并陪伴他们参与一些低风险的娱乐和运动项目，如露营、慢跑、散步等，培养兴趣爱好也有利于身心健康。采取保护措施，防止意外损伤。另外，不要刻意回避或否认患儿存在青少年期的一些特殊敏感问题，必要时应坦诚沟通，并告诉与癫痫发作的关系，帮助他们做出理智的决定。

**当然，家长还要注意一些细节，防止意外发生。**

**一、一般安全**

1. 对于周围环境要有安全意识，家人或朋友应了解患儿病情。

2. 告知亲近的朋友你的病情，并且告诉他们如果你有癫痫发作的情况下该怎么做。当癫痫发作时，它会帮助朋友避免陷入恐慌，同时也是避免可能伤害的最好方法。

3. 使用有安全开关的电动工具。如有情况发生，机器可以自动停止。

4. 避免登高或爬到高处。

**二、日常生活**

1. 用塑料代替玻璃，防止在癫痫发作过程中玻璃门、杯子等物品碎了伤到患儿。

2. 在壁炉，火炉或散热器周围放置安全装置，避免可能的灼伤。

3. 如果需要烹饪时，最好有另外的人在场陪伴，以免万一发作会导致烧伤.

4. 当使用煤气炉灶时，应将锅子手柄放置在炉灶的另一侧。这样可以在癫痫发作时减小发生意外的机会。

**三、与水有关的安全**

1. 任何与水有关的活动都可能是种潜在的风险，癫痫患儿尽量避免独自游泳，潜水，或自己洗澡.

2. 建议用淋浴，比浴缸更安全。

3. 热水温度最高不要超过摄氏43度。
